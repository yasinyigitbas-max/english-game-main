# English Home 3D: bedroom test (Godot 4.7.2, GL Compatibility)
Open project.godot in Godot 4.7.2 and press F5. The renderer is gl_compatibility on desktop and mobile. Don't switch to Forward+.
The prebuilt `.godot/imported` cache is included, so the first run doesn't need an import step.

Controls: stick bottom-left (touch with multitouch, or mouse drag), action button bottom-right (it shows a hand only when you are near an object). If an object has several actions, chips appear above the button. The pause button (top-right) opens the menu.
Flow: Main menu (Play / Settings / Quit) -> asleep in bed -> alarm -> wake_up -> sit on the bed edge -> stand -> free play.
Interactive objects: bed (make / sit / lie down / get up), alarm clock (turn off / set / check), bedside table (lamp, drawer), window (curtains, open/close, look out), wardrobe (open/close, get dressed = change outfit), desk (laptop, desk lamp, work = sits and types), bookcase (take book / read / put back), mirror, plant (water), light switch (ceiling light), door (opens, then "The rest of the house comes later.").
Every action shows a short present-continuous caption with a TR toggle and plays a Piper voice clip.
v8 phone + jobs: after character creation the door stays locked and the mission bar says "Pick up your phone." (pulsing glow + floating marker on the phone on the left bedside table, edge arrow when off-screen). Walk to the bedside table, choose "Pick up the phone": the camera pans down into the phone and the phone UI zooms out of its screen. The phone is the hub: Jobs (8 A1 jobs, each with icon, word, Turkish helper and a Piper voice line such as "Teacher. I am a teacher. I work at a school."), Grammar, Words, Me. Choosing a job saves it (save.json "job"), updates the mission ("Open the door.") and unlocks the door. Later the phone button in the HUD (top-right, red dot until a job is chosen) reopens the phone. Icons in ui/phone/ are drawn by tools/make_phone_icons.py (original, CC0).
Phone QA: `xvfb-run -a godot --path . --rendering-driver opengl3 res://qa_boot.tscn -- --qa-phone` writes screens/70-79_*.png and qa_phone.log.
Self-test: `xvfb-run -a godot --path . --rendering-driver opengl3 -- --qa` writes screens/*.png and qa.log.
